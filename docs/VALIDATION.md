- 1901–2100 的 2,400 个月，在周一／周日起始的两种布局中均连续、不重复、覆盖当月全部日期；五／六行紧凑布局不丢失月末日期。
- 春节前后的干支年、29／30 日两种除夕、闰月不重复传统节日。

- 菜单栏三种日期格式、旧仅图标配置回退、时间组合、设置恢复、跨午夜自动跟随今天，同时保留历史浏览位置。

Debug 与 Release 均编译通过。最终 Release `.app` 本地签名通过 `codesign --verify --deep --strict` 验证，并已实际启动。打包为当前主机的 arm64 应用，最低系统要求 macOS 26.0。

## 1.1 界面调整与公开 API 核查

- 状态栏去掉图标，底栏移除；节假日、设置与退出收入右上角菜单。
- 月份箭头扩大为 44×40 pt，已实际点击图标外侧空白并确认切月。
- 10 月五行、11 月六行均完整显示，五行布局比旧版减少约 120 pt 高度。
- 外观选择持久化并立即作用于设置和日历；移除实色选项。
- 深色保留原生 behind-window 磨砂，叠加 36% 黑色压暗层（由 48% 下调以增加通透度）；增强对比度时提高至 66%。农历从 9 pt 调整为 10 pt，深色采用 medium 字重，提亮辅助文字、假日红与节气绿。
- 实机检查深浅色和设置切换；确认已无面板背景／实色选项。对用户原始截图与新版截图的农历文字区域抽样，对比度约从 2.0:1 提升到 5.4:1。这是当前画面的像素估算，不代表所有动态背景均已通过无障碍审计。
- 不使用 Clear 玻璃承载密集日期。Apple 建议常规材质用于内容层，Regular Liquid Glass 用于文字较多的控件或弹层；Clear 仅适合媒体背景。
- 公开 `NSStatusItem` API 没有强制始终排在最右侧的排序能力；未使用私有默认项或 API。位置可由用户按住 ⌘ 拖动。

依据：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)、[NSVisualEffectView](https://developer.apple.com/documentation/appkit/nsvisualeffectview)、[NSStatusItem](https://developer.apple.com/documentation/appkit/nsstatusitem)。
